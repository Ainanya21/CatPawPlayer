## 1. 软件简介与核心特色

AinanPlayer 是一款专为 Windows 10 / 11 平台打造的原生 Fluent 2 / WinUI 3 影视聚合流媒体播放器：
* **原生视觉体验**：深度融合 Windows 11 Mica / Acrylic 材质，支持浅色/深色主题实时无缝切换；
* **多引擎万能爬虫**：原生兼容 TVBox、CatVod、王二小放牛娃猫源（9988）、豆源（2333）等全套数据协议；
* **双播放内核**：支持离线嵌入式 HLS 原生播放引擎与 **Yaozhi-MPV 极速硬件加速引擎**（支持 4K HDR、HEVC/H.265、杜比视界及 120FPS 超高帧率）；
* **实时媒体流探针**：自动侦测并呈现 4K / 1080P、HDR、音频编码与网络延迟状态徽章；
* **内嵌网盘控制台**：支持夸克、百度、阿里、115、UC 网盘手机扫码一键授权与 4K 高速转存播放。

## 3. 首次启动与使用声明

* 升级或首次打开软件时，将自动弹出《AinanPlayer 免责声明与使用条款》；
* 为确保用户知悉开源播放工具之合规属性与权利边界，首次启动将开启 **2 分钟（120秒）阅读倒计时**；
* 倒计时结束后点击 **「我已阅读并愿意承担相应责任」** 即可进入主界面；
* 后续在「设置」页面中可随时点击「免责声明」卡片复查完整条款（复查无需等待倒计时）。

## 4. 订阅源管理与添加指南

本软件交付时不内置任何受版权保护的视听资源，所有内容均由用户自行配置。

### 步骤：
1. 点击左侧导航栏的 **「订阅管理」**；
2. 点击右上角 **「➕ 添加订阅源」** 按钮；
3. 输入您的 TVBox / 猫源接口 URL（支持 `http://` / `https://` / Base64 编码地址等）；
4. 点击 **「保存并启用」**，软件将自动后台解析所有可用影视源并建立本地站点索引；
5. 在订阅列表中，点击任意站点可一键设为当前活跃源。

## 5. 全量分类浏览与智能筛选

1. 点击导航栏 **「全量分类」**；
2. 顶部提供 **「当前影视源」下拉切换器**，可自由在当前订阅的多条源站之间切换；
3. **一级分类 Tab 栏**：支持快速切换电影、连续剧、动漫、综艺、纪录片等频道；
4. **多级筛选器**：点击「展开筛选」，可根据类型、年份、地区、排序方式等进行精准过滤；
5. **智能返回保护**：从任意影片详情页返回分类列表时，系统将**完整保留**您此前选中的分类 Tab、筛选条件以及浏览滚动位置。

## 6. 影视详情与智能选集播放

1. 在卡片流中点击任意影片进入 **详情页**；
2. **多线路播放源**：顶部展示可用播放源（如「官源」、「4K专线」、「网盘线路」等），支持一键自由切源；
3. **响应式两端对齐选集**：
   * 选集区域左右边缘与海报和简介严格对齐；
   * 按钮采用标准等宽矩阵布局，智能消除文件大小与剧集数字干扰，完整显示「第 155 集 (2.7GB)」等长名称且不被截断；
4. **流媒体实时探针**：自动侦测视频真实码率、分辨率与 HDR 信息，实时点亮高画质徽章。

## 7. 双播放引擎配置 (MPV 与原生解码)

进入软件 **「设置」->「播放内核设置」**：

* **内置原生播放器**：基于离线 Hls.js 与系统硬件加速，零配置秒开；
* **Yaozhi-MPV 极速硬件加速内核（强烈推荐）**：
  1. 开启 **「优先使用 Yaozhi-MPV 极速硬件加速播放器」** 开关；
  2. 点击「浏览...」选择本地 `mpv.exe` 执行程序路径（如已配置环境变量可自动就绪）；
  3. 点击「测试启动播放器」验证运行状态；
  4. 享受 4K HDR 原盘渲染、超分辨率画质增强、多音轨切换与外挂字幕实时同步。

## 8. 内嵌配置中心与网盘授权

1. 进入 **「设置」->「网盘授权与配置中心」**，点击 **「🖥️ 打开配置中心」**；
2. 在内嵌控制台中，可对夸克、百度、阿里、115、UC 网盘进行手机客户端一键扫码授权；
3. 授权成功后，播放原画网盘资源时将自动高速转存并直链拉流，告别限速卡顿。

## 9. 聚合搜索与历史/收藏管理

* **聚合搜索**：在导航栏「聚合搜索」中输入影片关键词，系统将在所有可用源站中发起跨源并发搜索，横向分站点展示搜索结果；
* **观看历史**：自动记录每部影片的播放进度（百分比与时间点），点击即可直接无缝续播；
* **我的收藏**：在影片详情页点击「收藏」按钮即可一键归档至收藏夹，随时便捷重温。

## 10. 外观与卡片显示个性化设置

进入 **「设置」->「外观设置」**：

1. **应用主题**：支持「浅色模式」、「深色模式」与「跟随系统」；
2. **预设与自定义强调色**：提供经典蓝、猫爪紫、翡翠绿、琥珀金、珊瑚红、蔷薇粉等多种色彩，亦可使用调色盘自定义十六进制颜色；
3. **显示卡片底部副标题开关**：
   * 开启：在卡片标题下方展示「年份 / 类型 / 高清视频」等副标题；
   * 关闭：隐藏底部副标题，使卡片排列更紧凑；
4. **显示图片右上角角标开关**：
   * 开启：在剧集海报右上角展示「4K HDR / 更新至第X集 / 已完结」等角标；
   * 关闭：隐藏角标，呈现原汁原味的海报画面。
   * *(注：以上开关切换后即时生效并持久化保存。)*

## 12. 常见问题解答 (FAQ)

### Q1: 为什么打开全量分类提示“暂无影视订阅源”？
* **解答**：本播放器为纯壳播放工具，首次使用时请前往「订阅管理」页面添加您自备的 TVBox 或猫源订阅接口地址。

### Q2: 播放网盘类 4K 影片时提示需要登录或解析失败？
* **解答**：请前往「设置」页面点击「打开配置中心」，使用手机 App 扫描对应网盘的二维码完成授权登录即可。

### Q3: 升级安装后我之前的历史记录和收藏还在吗？
* **解答**：在的。覆盖安装时所有用户数据（保存在 `%LOCALAPPDATA%\CatPawPlayer`）均会完整保留，不会受到安装或更新的影响。

### Q4: 如何切换使用外部 MPV 播放器？
* **解答**：在「设置」-「播放内核设置」中勾选启用 MPV 并填入 `mpv.exe` 的路径即可。播放时也可以在影片详情页通过「MPV 极速播放」开关对单部影片进行针对性切换。
