1. 软件简介与核心特色

AinanPlayer 是一款专为 Windows 10 / 11 平台深度打造的原生 Fluent 2 / WinUI 3 影视聚合流媒体播放器，拒绝套壳网页浏览器的内存黑洞与掉帧卡顿，提供如同系统原生应用般丝滑的交互体验：

原生视觉美学

深度融合 Windows 11 Mica / Acrylic 材质，支持浅色/深色模式实时无缝切换，更有 4 款专属品牌高质感图标实时热切换。

多引擎万能爬虫

原生兼容 TVBox、CatVod、王二小放牛娃猫源（9988）、豆源（2333）等全套数据协议，支持海量公开源规则。

双轨 Yaozhi-MPV 加速

内置与外置均全面基于 Yaozhil/mpv-Yaozhi。原生支持 4K HDR、HEVC/H.265、杜比视界及 120FPS 超高帧率极速渲染。

内嵌网盘扫码控制台

集成夸克、阿里、百度、115、UC 网盘手机扫码授权中心，直解 4K 原画资源，告别第三方限速卡顿。

2. 下载与安装覆盖说明

单文件安装版 (AinanPlayer_vX.X.X_Setup.exe) • 强烈推荐

采用现代化的单文件安装向导，极速解压释放。支持自定义安装盘符，自动配置桌面与开始菜单快捷方式。

覆盖升级说明：新版本安装包可直接覆盖安装，无损保留所有历史记录、收藏夹与已配置的订阅源。

绿色免安装便携版 (AinanPlayer_vX.X.X_Portable.zip)

解压至任意文件夹或随身 U 盘中，双击直接运行 AinanPlayer.exe 即可使用，随拷随走，适合多台设备移动观影。

3. 首次启动与使用声明

首次启动或升级启动软件时，应用将自动弹出《AinanPlayer 免责声明与使用条款》。

3 分钟（180秒）合规阅读倒计时说明

为确保所有使用者充分知悉本开源播放工具之合规属性与权利边界（本工具仅作为协议渲染壳，不内置任何影视内容），首次启动将开启 180 秒阅读计时。

倒计时结束后，点击 「我已阅读并愿意承担相应责任」 按钮即可永久进入主界面。后续在「设置」页面中可随时复查完整条款（复查时无需等待倒计时）。

4. 订阅源管理与添加指南

AinanPlayer 本身不内置、不提供任何影视媒体资源。添加您自备的订阅规则即可开始畅享：

第一步：进入订阅管理

点击应用顶部居中导航或侧边菜单中的 「订阅管理」。

第二步：点击添加订阅源

点击页面右上角的 「添加订阅源」 按钮，弹出输入对话框。

第三步：输入订阅 URL 并保存

输入您的 TVBox 或猫源接口地址（支持 http://、https:// 或 Base64 编码源），点击 「保存并启用」。

第四步：自动解析与自由切源

客户端将全自动解析该订阅配置的所有站点并建立本地索引。在站点列表中点击任意条目即可秒级设为当前活跃源。

5. 首页推荐换源与全量分类浏览

首页推荐与即时切源

在「首页推荐」页面顶部，提供 「当前影视源」下拉切换菜单。无需进入繁琐设置，直接在此切换活跃源，首页精选轮播与分类内容将无感联动秒刷。

全量分类与智能筛选

进入「全量分类」页面，顶部清晰展示一级分类 Tab（电影、电视剧、动漫、综艺等）。点击「展开筛选」，可按题材、年份、地区多维度组合过滤。

智能记忆保护

点击任意影片进入详情后，再点击返回键，系统将 100% 完整保留 您之前选中的分类 Tab、筛选器状态以及海报流滚动高度，无需重新滚动寻找。

6. 影视详情与智能选集播放

  • 多线路播放源：详情页顶部展示该影片所支持的全部播放源（官源、4K专线、网盘原画线路等），若某线路偶尔卡顿可一键无缝切线。
  • 响应式两端对齐选集：选集矩阵左右严格对齐，支持极速跳选集数，完整支持包含文件大小与剧集名称的长标签排版。
  • 实时媒体流探针：开始点播后，系统自动嗅探并呈现真实的 4K / 1080P、HDR、音频编码与网络延迟徽章。

7. 双播放引擎配置 (MPV 与内外置)

AinanPlayer 的播放核心全面基于活跃优秀的 Yaozhil/mpv-Yaozhi，独创提供内置便携开箱即用与外置极客专属定制双轨模式：

模式一 • 默认内置

内置便携内核（免配置 · 原生内嵌）

软件安装自带调优便携版引擎，直接点播影片即可。原生嵌入在 WinUI 3 窗口中播放，支持 4K UHD、HEVC、HDR、杜比视界，普通用户无需任何设置。

模式二 • 发烧外置

外置自定义内核（独立窗口 · 发烧友首选）

支持加载用户本地定制的 Yaozhi-MPV 环境。完美继承您的 mpv.conf、Anime4K / FSRCNNX 着色器、Lua 脚本与快捷键。

外置 MPV 配置步骤： 前往 「设置」->「播放内核设置」，开启「启用外部 MPV 硬件加速播放」开关，点击「浏览...」指定外部 mpv.exe 路径，点击「测试启动播放器」验证即可全局生效。

8. 内嵌配置中心与网盘授权

若您的订阅源中包含网盘类原画高清资源（如夸克、百度、阿里、115、UC 网盘）：

  1. 进入 「设置」->「网盘授权与配置中心」；
  2. 点击 「打开配置中心」，应用将弹出专属网盘控制台；
  3. 使用手机端对应网盘 App（例如夸克 App 扫码登录）完成扫码授权；
  4. 授权成功后状态实时同步，点播 4K 网盘原画视频时客户端将全自动高速拉流，无任何限速。

9. 聚合搜索与历史/收藏管理

聚合全网搜索

在搜索框输入关键词，客户端将向所有已配置的源站点发起多线程并发检索，横向按站点分类直观呈现。

播放进度记忆

自动精准记录每部影片每集的播放进度与时间戳，重新打开即可一键无缝续播，无需手动快进。

本地与云端收藏

在详情页轻触红心即可加入收藏夹，建立您的专属影视片单库，换源追剧井井有条。

10. 外观与卡片显示个性化设置

前往 「设置」->「外观设置」 可随心所欲定制您的专属视觉风格：

1. 深浅色主题模式：支持「浅色模式」、「深色模式」或「跟随 Windows 系统」自动无感切换。
2. 4 款品牌图标热切换：
经典蔚蓝 (默认)
幻彩粉紫
曜石银黑
霓虹暗夜

点击卡片即可实时生效，任务栏、原生窗口以及标题栏图标无缝同步更换，无需重启客户端。

3. 卡片布局开关：支持独立开启或关闭「显示卡片副标题」与「显示右上角角标（4K HDR/更新集数）」，打造极简海报瀑布流。

11. 应用内一键在线更新

进入 「设置」->「关于与软件更新」，客户端启动或进入该页面时会自动比对 GitHub Releases 最新版本。

当发现新版本时，点击 「立即下载更新」，应用将自动通过多镜像高速通道下载安装包并在下载完毕后一键无损覆盖升级，免去手动去浏览器搜索下载的繁琐。

12. 常见问题解答 (FAQ)

Q: 为什么打开全量分类提示“暂无影视订阅源”？

答：本播放器为纯粹开放协议渲染客户端，首次使用请前往「订阅管理」页面添加您自备的 TVBox 或猫源规则地址。

Q: 播放网盘类 4K 影片时提示需要登录或解析失败？

答：请前往「设置」页面点击「打开配置中心」，使用手机客户端扫描对应网盘的二维码完成授权登录即可。

Q: 覆盖升级安装后我之前的历史记录和收藏还在吗？

答：完全在。覆盖安装时所有用户数据与配置（保存在本地应用数据目录中）均会完整保留，不受版本更新影响。

Q: 正式版与内测版有什么区别？我该如何选择？

答：官方正式稳定版本为 v3.5.0，面向所有普通大众用户完全免费开放，经过近千名用户实机测试，日常观影最为稳妥；v3.9.9 内测版 包含最新迭代的观看历史单条删除与同剧去重、连续切集防断流秒播、全量分类瀑布流、超长剧集快捷分组等前沿特性，需要捐赠支持本项目才可下载使用。
